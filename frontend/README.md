# 🍽️ Gourmet Harvest — Restaurant UI

A modern and responsive restaurant landing page designed for a romantic,
couple-friendly dining experience.

Gourmet Harvest focuses on a warm, elegant restaurant interface with
North Indian food cards, smooth navigation, responsive layouts and
a visually rich background.

## 📌 About The Project

Gourmet Harvest is a frontend restaurant UI project built using
HTML and CSS.

The website is designed around a couple-friendly restaurant concept,
with sections for the restaurant introduction, menu, contact,
customer support and footer navigation.

The main goal of this project was to practice and strengthen
core frontend concepts before moving towards backend development.
